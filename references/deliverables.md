# 五份阶段成果规格

五步法每一步只交付一份成果，且这份成果是下一步的**唯一输入**。用于检查输出是否完整、是否达标。

## 交接总表

| 步骤 | 核心问题 | 核心方法 | 阶段成果 | 进入下一步的条件 |
| --- | --- | --- | --- | --- |
| 01 AI访谈 | 项目到底是什么、要什么 | 顾问式访谈 + 需求澄清 | 《项目营销需求简报》 | 用户已确认或修改简报 |
| 02 营销定位 | 客户凭什么买 | 用户需求三问法 + 价值主张设计 | 《营销定位策略卡》 | 优先人群与购买理由已明确且有依据 |
| 03 内容策划 | 做什么内容、发到哪里 | 用户旅程 + 内容资产复用 + 渠道匹配 | 《7天内容营销与分发执行表》 | 每条内容都挂了营销任务 |
| 04 转化闭环 | 看完内容之后客户往哪走 | 用户行动路径 + 客户承接 + 反馈循环 | 《营销转化与反馈闭环图》 | 每个关键环节有负责人或待落实标注 |
| 05 整合成案 | 能不能真的执行 | 方案整合 + 可行性检查 + 行动清单 | 《AI内容营销执行方案》 | 已逐项做完最终检查 |

用户需求三问法：**谁在买？什么时候买？凭什么选择？**

---

## 01《项目营销需求简报》

必备十项：项目介绍、核心产品、目标用户、用户需求、营销目标、产品价值与证据、已有内容资产、营销渠道、承接条件、资源约束。

三类信息分区：**已确认事实 / 待验证假设 / 待补充资料**。

另需指出「最影响方案落地的关键缺口」，并请用户确认或修改后再进入第二步。

访谈需覆盖的八个方面：产品或服务是什么、目标用户是谁、用户有什么需求及为什么可能购买、希望实现什么营销目标、已有哪些图片海报视频和资料、准备使用什么营销渠道、有多少预算人力和时间、用户如何咨询预约或购买。

用户已一次性给全背景时，跳过逐一提问，直接整理本简报，但仍须请用户确认。

## 02《营销定位策略卡》

七个输出字段：优先目标用户、典型购买场景、核心需求或痛点、产品能提供的具体价值、支持购买理由的证据、一句话营销定位、一句通俗易记的传播主张。

生成前的过程要求：找出 2—3 类可能目标用户并分析需求/场景/关注点 → 推荐一个优先人群并解释原因 → 将产品真实特点与用户需求匹配 → 找出 1—3 个优先传播的购买理由 → 区分已证实卖点与待验证假设。

定位必须回答的核心问题：在现有资源条件下，应该优先面向哪一类客户、突出哪一个**有依据**的购买理由。

## 03《7天内容营销与分发执行表》

九列固定表头：日期、目标用户、内容主题、营销任务、内容形式、复用素材、发布渠道、行动引导、制作状态。

内容矩阵按用户决策过程分三类，每条内容必须说明承担的营销任务：

- **认知内容**：让用户认识产品或品牌（回答「你是谁」）
- **了解内容**：解决疑问、展示价值（回答「你有什么不同」）
- **行动内容**：帮助有意向的用户咨询或购买（回答「我该怎么进一步了解」）

前置动作是盘点已有内容资产（产品图、包装图、营销海报、广告视频、品牌资料），判断「可直接用 / 需改编 / 必须补充」，优先复用，避免重复制作。渠道从抖音、小红书、视频号及企业自有渠道中选择，并说明同一素材是否需要调整。若用户已限定可用渠道，以限定范围为准，不得擅自扩展。

投放部分：资料不足时只给测试建议，不虚构预算、效果或收益。预算为 0 或用户明确不投放时，写明「本轮不执行付费测试」即可，不提供金额、效果或收益预估。

## 04《营销转化与反馈闭环图》

完整路径（**以本文件六节点为准**）：看见内容 → 产生兴趣 → 进一步了解 → 采取行动 → 获得服务 → 反馈回流。`prompts.md` 第四步提示词中的五节点是同一路径的压缩表述，不视为冲突，不改写提示词原文。

路径每一步都要写清五件事：用户可能在想什么、需要什么信息、企业应采取什么动作、使用什么内容、用户下一步去哪里。

配套四个部分：

1. **行动引导**：了解产品、查看商品详情、咨询服务、预约体验、进入正规购买渠道等，须符合项目实际条件与平台规则。
2. **客户承接**：谁接收咨询、用什么渠道、常见问题怎么答、如何完成购买预约服务、哪些环节待补条件。
3. **反馈循环**：选 3—5 项最必要的基础记录（内容触达、用户点击、有效咨询、预约、订单、常见用户问题等），说明如何把反馈变成下一轮选题；不做复杂统计分析。
4. **责任标注**：图中标明每个关键环节的**负责人或待落实事项**。

这一步得到的不是一张好看的流程图，必须包含明确行动。购买入口未建立时，须标注「待落实销售渠道」，不得默认企业已开通网店。

## 05《AI内容营销执行方案》

九个章节：一 项目与营销目标 / 二 目标用户与营销定位 / 三 内容资产与营销策略 / 四 内容矩阵与7天分发计划 / 五 内容投放建议 / 六 客户转化与私域承接 / 七 执行安排 / 八 反馈与后续优化 / 九 风险与待验证事项。

输出顺序固定：

1. 一页《营销方案总览表》
2. 详细执行方案（九章）
3. 「优先执行的5项任务清单」

**《营销方案总览表》固定为五行三列**：五个模块行（目标与定位 / 内容与分发 / 投放建议 / 转化与反馈 / 执行清单）× 三列（模块 / 核心结论 / 关键条件或状态）。只做一页，不展开论证。

**第四章口径**：直接复用第三步的九列表，或按需精简为五列摘要（内容主题 / 内容形式 / 目标渠道 / 行动引导 / 执行安排）。两种都属整合，不算第五步发散，也不算重新构思方案；表名沿用《7天内容营销与分发执行表》。

**最终检查七项**（逐项检查，发现矛盾要明确指出并修改）：

1. 营销目标与内容安排是否一致
2. 目标用户是否明确
3. 产品卖点是否有真实依据
4. 内容与分发渠道是否匹配
5. 用户行动路径是否完整
6. 执行工作量是否符合实际资源
7. 有哪些关键条件尚未落实

缺乏依据的内容一律标注「待核实」，不得当成事实。语言通俗、表格清晰、避免空泛营销术语。

最终方案的五个组成部分：目标与定位 / 内容与分发 / 投放建议 / 转化与反馈 / 执行清单。既要有给负责人看的一页总览，也要有能分配任务、按步骤执行的详细计划。

## 通用质量门槛

- 阶段成果使用固定名称，便于下一步引用与结果核对。
- 输出中「事实」「假设」「待补充」必须分开表述，不得混写。
- 数字、渠道入口、客户数据、成交成果一律不得凭空生成。
- 第五步不再发散新创意，只做整合、优化、检查与行动清单。
