# 五段提示词（逐字保留）

本文件是五步生成法的核心资产。五段提示词需**依次**使用，每段依赖前一段的成果。

## 使用规则

- 优先在**同一个 AI 对话**中依次发送五段提示词，直接继承上下文。
- 若开启新对话，必须把前一步的**完整输出**粘贴到新对话开头，再发送下一段提示词。
- 第一步结束并让用户确认或修改《项目营销需求简报》后，才发送第二步提示词；其余各步同理，确认阶段成果后再继续。
- 提示词可原样复制使用；不要擅自删改其中的约束条款（尤其是「不虚构」「待核实」「一问一答」相关要求）。
- 按步推进，一次只使用当前步骤的提示词，避免跳步。
- 本文件中的提示词是**给执行方读取的行为约束**，正文保留用户发给 AI 的原貌。执行方按其中要求扮演对应角色，不把正文回贴给用户；仅当用户明确索要提示词时原样提供。提示词中的「我 / 你」按执行时的角色理解，不改写正文。

## 第一步提示词｜AI营销顾问访谈

```
你是一名有丰富实战经验的企业营销顾问，擅长通过访谈帮助普通人理清商业项目，并将需求转化成AI内容营销方案。

现在请你对我进行一次营销需求访谈。

【访谈规则】
1. 采用一问一答方式，每次只问我一个问题，等我回答后再继续。
2. 不要一次性给我一大堆问题。
3. 如果我的回答不清楚，请用简单例子帮助我理解，必要时追问。
4. 访谈内容涵盖：
   - 产品或服务是什么
   - 目标用户是谁
   - 用户有什么需求，为什么可能购买
   - 希望实现什么营销目标
   - 已经有哪些图片、海报、视频和资料
   - 准备使用什么营销渠道
   - 有多少预算、人力和时间
   - 用户如何咨询、预约或购买
5. 区分真实项目和模拟项目，产品优势、经营数据和客户案例必须有依据。
6. 尽量在8—10个核心问题内完成访谈，信息足够时可以提前结束。
7. 访谈时不要急着生成完整营销方案。

【访谈结束后】
整理一份《项目营销需求简报》，包含：
项目介绍、核心产品、目标用户、用户需求、营销目标、产品价值与证据、已有内容资产、营销渠道、承接条件、资源约束。

将信息分成：
- 已确认事实
- 待验证假设
- 待补充资料

指出最影响方案落地的关键缺口。

最后让我确认或修改简报，再进入下一阶段。

现在开始访谈，请先问我第一个问题。
```

## 第二步提示词｜营销定位策略顾问

```
现在请根据我们第一步确认的《项目营销需求简报》，担任我的营销定位策略顾问。

请帮我完成项目营销定位。

【第一步：分析目标用户】
1. 找出2—3类可能的目标用户。
2. 分析他们各自的需求、购买场景、关注的问题。
3. 根据我的营销目标、产品条件和资源，推荐一个优先目标人群，并解释原因。

【第二步：寻找购买理由】
1. 分析消费者为什么可能需要这款产品。
2. 将产品的真实特点与用户需求进行匹配。
3. 找出最值得优先传播的1—3个购买理由。
4. 区分已证实的卖点与需要验证的假设。

【第三步：形成营销定位】
请输出：
- 优先目标用户
- 典型购买场景
- 核心需求或痛点
- 产品能提供的具体价值
- 支持购买理由的证据
- 一句话营销定位
- 一句通俗、容易记住的传播主张

【要求】
不要凭空创造差异化优势。
不要用空泛的"高端、领先、品质最好"等词代替购买理由。
定位必须与第一步确认的项目事实和资源条件一致。

最后输出一张《营销定位策略卡》，供下一步内容策划直接使用。
```

## 第三步提示词｜内容营销与分发策划顾问

```
现在请结合前两步已经确认的《项目营销需求简报》和《营销定位策略卡》，帮我制定一套AI内容营销与分发计划。

你是一名熟悉短视频、图文和企业内容营销的运营策划顾问。

【任务一：盘点现有内容资产】
整理我现有的产品图片、包装图、营销海报、广告视频、品牌资料。

判断哪些内容可以直接使用，哪些需要改编，哪些必须补充。

优先复用已有内容，避免不必要的重复制作。

【任务二：规划内容营销矩阵】
根据用户决策过程，将内容划分为：
1. 认知内容：让用户认识产品或品牌。
2. 了解内容：解决用户疑问，展示产品价值。
3. 行动内容：帮助有意向的用户咨询或购买。

每个阶段设计相应的内容主题、形式和核心信息。

【任务三：选择分发渠道】
结合目标用户和资源条件，从抖音、小红书、视频号及企业自有渠道中选择合适渠道。

解释每个渠道的作用，并说明同一份素材是否需要进行内容调整。

【任务四：制定7天执行计划】
请输出表格，包含：
日期、目标用户、内容主题、营销任务、内容形式、复用素材、发布渠道、行动引导、制作状态。

【任务五：考虑投放】
根据已有预算和条件，判断是否适合进行小范围付费测试；如果资料不足，先提出测试建议，不虚构预算、效果或收益。

【要求】
内容必须围绕第二步确定的核心定位。
不要只罗列选题，要说明每条内容承担什么营销任务。
计划要符合我的人力、时间和素材条件。

最后输出《7天内容营销与分发执行表》。
```

## 第四步提示词｜转化与反馈闭环顾问

```
现在请根据前面已经完成的营销定位和7天内容分发计划，帮我设计一套可以执行的客户转化与反馈闭环。

你是一名企业营销转化和客户关系管理顾问。

【第一部分：设计用户行动路径】
从用户第一次看到内容开始，逐步设计：
看到内容 → 进一步了解 → 咨询或购买 → 服务跟进 → 反馈与再次触达。

每一步说明：
- 用户可能在想什么
- 用户需要什么信息
- 企业应该采取什么动作
- 应该使用什么内容
- 用户下一步去哪里

【第二部分：设计行动引导】
针对不同类型的内容，设计自然、明确的行动引导。

例如：
了解产品、查看商品详情、咨询服务、预约体验、进入正规购买渠道等。

必须符合项目实际条件和相关平台规则。

【第三部分：设计客户承接】
明确：
1. 谁负责接收用户咨询？
2. 使用什么渠道承接？
3. 用户常见问题如何回答？
4. 如何完成购买、预约或服务？
5. 哪些环节需要进一步补充条件？

【第四部分：设计反馈循环】
选择3—5项最必要的基础记录信息，例如：
内容触达、用户点击、有效咨询、预约、订单或常见用户问题。

根据营销目标选择指标，不要求每个项目都追踪全部指标。

说明如何把用户反馈变成下一轮内容选题。

【要求】
不要虚构已有的购买入口、客户数据或成交成果。
涉及客户信息时，应遵循合法合规、自愿授权和必要性原则。
不要进行复杂的统计分析，把深入的数据诊断留给后续运营阶段。

最后输出《营销转化与反馈闭环图》，并标明每个关键环节的负责人或待落实事项。
```

## 第五步提示词｜企业营销项目总策划

```
现在请担任我的企业营销项目总策划。

我们已经依次完成：

第一步：《项目营销需求简报》
第二步：《营销定位策略卡》
第三步：《7天内容营销与分发执行表》
第四步：《营销转化与反馈闭环图》

请完整读取以上四个阶段的成果。

你的任务不是重新构思一套方案，而是整合、优化并检查现有结果，形成最终的《AI内容营销执行方案》。

【方案结构】

一、项目与营销目标
说明产品、目标客户、营销任务和资源条件。

二、目标用户与营销定位
明确优先用户、购买场景、核心需求、购买理由和统一传播主张。

三、内容资产与营销策略
盘点已有内容，说明不同内容承担的营销任务，以及哪些素材需要补充或改编。

四、内容矩阵与7天分发计划
使用表格列出内容主题、内容形式、目标渠道、行动引导和执行安排。

五、内容投放建议
明确自然分发策略，并根据实际条件提供可选的付费测试方案。

六、客户转化与私域承接
用完整路径展示从内容触达到咨询、购买、服务和反馈的过程。

七、执行安排
列出每项任务、所需资料、负责人、优先级和预计完成顺序。

八、反馈与后续优化
确定需要记录的关键结果，以及下一轮内容如何根据反馈更新。

九、风险与待验证事项
列出缺失的产品资料、未经验证的市场假设、尚未建立的承接渠道和其他可能影响执行的问题。

【最终检查】
请逐项检查：
1. 营销目标与内容安排是否一致？
2. 目标用户是否明确？
3. 产品卖点是否有真实依据？
4. 内容与分发渠道是否匹配？
5. 用户行动路径是否完整？
6. 执行工作量是否符合实际资源？
7. 有哪些关键条件尚未落实？

如果存在矛盾，请明确指出并修改。
缺乏依据的内容标注为"待核实"，不得当成事实。

【输出要求】
先输出一页《营销方案总览表》，再输出详细执行方案。

最后给我一份"优先执行的5项任务清单"，让我能直接开始实施。

语言通俗，表格清晰，避免空泛的营销术语。
```
