# 方法示例：一份营销方案的产出形态

以下示例仅用于说明每一步的成果长什么样，**不是经过市场验证的最优策略，也不构成对具体产品的推荐**。示例中的产品信息（产地、品种、质量、价格等）均为「待核实」。

示例产品：一款面向家庭日常采购的大米。

## 02 步｜定位策略卡示例

| 定位项目 | 示例值 |
| --- | --- |
| 优先用户 | 城市家庭日常采购者 |
| 典型场景 | 家庭日常做饭 |
| 用户关注 | 产地、口感、规格、价格、购买便利性 |
| 价值方向 | 围绕日常家庭餐桌需求进行传播 |
| 传播主张 | 一碗好米饭，认真吃好每一天 |
| 待核实 | 具体产品的产地、品种、质量和价格信息 |

要点：定位不是「列出十个卖点」，而是在现有资源条件下回答「优先面向哪一类客户、突出哪一个**有依据**的购买理由」。表中「待核实」一行不可省略。

## 03 步｜内容安排示例

四种内容任务的示意，**不是已经确定的发布日程**：

| 内容任务 | 内容主题 | 内容形式 | 渠道方向 |
| --- | --- | --- | --- |
| 认识 | 一碗家常米饭的日常场景 | 情景短视频 | 短视频平台 |
| 了解 | 这袋米的产地、品种和规格 | 产品图文 | 图文平台、商品详情页 |
| 了解 | 家庭买米时需要关注哪些信息 | 选购知识内容 | 短视频、图文平台 |
| 行动 | 如何选择规格以及在哪里购买 | 产品购买说明 | 企业自有渠道、合规销售入口 |

要点：每条内容都挂着明确的营销任务（认知 / 了解 / 行动），并优先复用已有素材。真正的《7天内容营销与分发执行表》还需补齐日期、目标用户、复用素材、行动引导、制作状态等九列。

## 04 步｜闭环标注的反面案例

若该产品的购买入口尚未建立，方案必须标注「**待落实销售渠道**」，不能默认企业已经开通网店或私域承接。

同理，客服、常见问题话术、订单记录方式若未确认，一律标「待落实」并写明责任归属，不得在路径图上画成已存在的环节。

要点：这一步得到的不是一张好看的流程图，而是「谁在哪个环节做什么、还缺什么条件」。
