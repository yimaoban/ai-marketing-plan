# ai-marketing-plan

> 把「一个产品 / 一个项目」通过五次对话，变成一份能分配任务、按步骤执行的营销方案。

一个面向 WorkBuddy / CodeBuddy 的技能（Skill）。五步严格串行，上一步成果直接成为下一步输入，最终产出不是看起来漂亮却落不了地的商业计划书，而是**能直接干活的执行方案**。

## 五步流程

| 步 | 核心问题 | 阶段成果 |
| --- | --- | --- |
| 01 | 项目是什么、卖给谁、要什么 | 《项目营销需求简报》 |
| 02 | 客户凭什么买 | 《营销定位策略卡》 |
| 03 | 做什么内容、发到哪里 | 《7天内容营销与分发执行表》 |
| 04 | 看完内容客户往哪走 | 《营销转化与反馈闭环图》 |
| 05 | 能不能真的执行 | 《AI内容营销执行方案》 |

每步设「过关门」，成果经确认后才进入下一步。内置事实/假设/待补三分法、禁止虚构数据与购买入口、示例不得当结论等质量约束。

## 安装

```bash
git clone https://github.com/yimaoban/ai-marketing-plan.git
```

把整个仓库文件夹（含 `SKILL.md` 和 `references/`）放到技能的加载目录，并确保文件夹名为 `ai-marketing-plan`：

- macOS / Linux：`~/.workbuddy/skills/ai-marketing-plan/`
- Windows：`C:\Users\<你的用户名>\.workbuddy\skills\ai-marketing-plan\`

然后**重开一次对话或刷新技能列表**，技能才会被加载。

> 也可以点 GitHub 页面的 **Code → Download ZIP**，解压后把 `ai-marketing-plan` 文件夹放进同一目录。

## 使用

技能会自动识别意图，也可以直接这样说：

- 「帮我给这个产品做一份营销方案」
- 「用五步法走一遍」
- 「把手上这些素材排成一周的内容分发计划，并设计从内容到咨询的路径」

若已一次性提供完整项目背景，说明「背景已给全，直接往下走」即可——技能会先整理《项目营销需求简报》请你确认，再继续，不会跳步。

## 文件结构

```
ai-marketing-plan/
├── SKILL.md                         # 流程、铁律、过关门、资源索引
└── references/
    ├── prompts.md                   # 五段提示词原文（核心资产）
    ├── deliverables.md              # 五份成果字段规格 + 最终检查
    ├── examples.md                  # 产出形态示例（未经市场验证）
    └── quality-checks.md            # 执行质检清单
```

首次触发时会一次性读完四份 references；之后按每步需要回查对应段落。提示词作为技能的行为约束使用，不会回贴给你，除非你明确要求复制。

## 已知限制

- 只做方案设计与执行安排，**不覆盖**发布后的数据诊断、指标归因与持续优化。
- 不替代法律、广告合规、平台规则与 AI 生成内容标识的审核。
- 五步依赖同一对话上下文；换对话须粘贴前一步完整输出。
- `references/examples.md` 仅为产出形态示范，未经市场验证，不得当最优策略。
- 不生成图片、视频等素材，只规划内容任务与已有素材的复用方式。
- 不收集、不回传任何使用数据；所有信息只留在当前对话。
